# EvSafe App Service

## build command
mmm packages/apps/Car/EVSafe

## apk path
/home/chank/aaos/out/target/product/emulator_x86_64/system/priv-app/EVSafe

# How to Use
1. Drag & Drop EVSafe.apk
2. Go to Settings in the emulator
3. Allow Permission
 **Settings --> Apps --> Permissions --> Additional permissions --> Navigation / Car information --> Allow**
